# Back end

this is a backend focus application that i developed following a youtube video. I was able to add some features on my own, learn some  new tricks from reading *README.MD* file.

One instance is enabling **Markdown** when you create a post. You are able to input markdown text on the posts.

Also you can add images and links to the body.

Additionally the forms popup for login and sign in. This i achieved by adding an additional `javascript` file and another `CSS` stylesheet.

There is still more to improve in the app.
